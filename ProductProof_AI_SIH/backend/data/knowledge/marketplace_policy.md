# Marketplace Image Verification Policy
1. Product images must represent the actual product being sold.
2. Images must not intentionally misrepresent brand, model, color, category or key specifications.
3. Multiple images in one listing should depict the same product.
4. Poor or ambiguous images should go to human review.
5. Manufacturer documentation is preferred over seller claims.
6. Automated rejection requires sufficiently strong evidence.
7. Preserve evidence explaining every flagged listing.
